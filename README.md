# 证照台账 · 连锁门店证照管理系统

面向连锁餐饮门店的证照登记、续证、审核与到期提醒系统。总部法务统一配置提醒策略并审核换证，门店负责人只管理本店资料；SQLite 保存证照版本链与审核链，扫描件本地存储，提醒在进程内执行，送达回执由模拟适配器返回。

## 快速开始

```bash
npm install
npm start          # 首次启动自动建库并生成 4 家门店 × 3 类证照的样例数据
# 打开 http://localhost:3000
```

演示账号：

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 总部法务 | `hq` | `hq123` |
| 门店负责人 | `store1` ~ `store4` | `store123` |

运行测试：`npm test`（9 个用例：过期拦截、地址变更、版本切换、并发审批、数据隔离）。

## 交付功能

- **证照矩阵**（总部）：门店行 × 证照列，单元格显示剩余天数、待办人（门店负责人 / 总部法务）、异常标记；临期冷灰底，**仅真正过期用朱红**。
- **到期看板**：按剩余天数升序，进度条 + 责任人。
- **续证任务**：门店上传续证材料并记录受理号；任务状态机 待提交→已提交→（驳回/补正）→完成/逾期。
- **材料补正**：总部登记补正要求，门店补正后闭环。
- **审核记录**：提交 / 通过 / 驳回 / 补正 / 标记全链路留痕。
- **证照详情**：扫描件按原始宽高比完整展示（不裁剪），版本时间线 + 审核链同屏。
- **提醒回执**：进程内定时巡检（默认 60s），临期自动建任务并发送提醒，模拟适配器返回送达回执号并落库；同一任务 24 小时内不重复打扰。
- **类型配置**：总部法务按证照类型配置提醒提前量（天）。

## 业务规则

| 规则 | 实现 |
| --- | --- |
| 过期拦截 | 出示/核验证照时过期 → `409 LICENSE_EXPIRED`；巡检自动置 `expired` 并打「临期未提交」标记 |
| 迁址/经营范围变更 | 全店证照置「待核查」，旧证出示 → `409 RECHECK_REQUIRED`；按新址换证且总部通过后才解除，全部证照核查完成后变更单归档 |
| 版本切换 | 新版本默认 `pending_review`，**仅总部审核通过**才成为当前有效版本，旧版本原子作废；任一时刻仅一个 `current` |
| 并发审批 | 条件更新 `WHERE status='pending_review'`，并发下只有一人成功，其余 `409 ALREADY_REVIEWED` |
| 数据隔离 | 中间件按门店过滤：跨店读写、越权审核一律 `403`；未登录 `401` |
| 有效期衔接 | 审核通过时比对新旧证日期，断档/异常重叠自动打「有效期衔接异常」标记 |
| 五类标记 | 受理驳回、临期未提交、原件遗失、扫描件模糊、有效期衔接异常（另有变更待核查） |

## 架构

```
server.js            入口：建库 → 播种 → 首次巡检 → 启动 HTTP + 进程内提醒调度
src/db.js            SQLite（node:sqlite）schema + 同步事务
src/app.js           Express 应用工厂（注入 db/扫描件目录/通知适配器，便于测试）
src/reminders.js     提醒巡检引擎（runSweep 可注入“今天”，便于确定性测试）
src/notify.js        模拟送达适配器（返回回执号，支持注入失败）
src/flags.js         标记引擎（同类未决标记幂等）
src/seed.js          多门店样例数据（覆盖全部业务状态）+ SVG 扫描件生成
public/              原生前端（冷白 + 深灰 + 少量朱红）
test/                node:test 五组集成测试（真实 HTTP 服务 + 临时 SQLite）
data/                运行时生成：license.db + scans/（勿提交）
```

关键 API：`POST /api/login`、`GET /api/matrix`、`GET /api/dashboard/expiry`、`POST /api/licenses/:id/versions`（上传续证材料+受理号）、`POST /api/versions/:id/review`（总部审核/版本切换）、`POST /api/licenses/:id/use`（出示核验/过期拦截）、`POST /api/stores/:id/changes`（迁址触发核查）、`GET /api/renewals|corrections|reviews|flags|reminders`、`PUT /api/license-types/:id`（提醒提前量）。

## 设计说明

界面以冷白（`#f4f6f8`）为底、深灰（`#2c343d`/`#33414e`）为结构与文字主色；朱红（`#bd3a26`）只出现在**真正过期**的证照上（矩阵单元格、看板天数、状态徽章），临期与待核查使用冷灰/暖灰区分，避免整页警示色。
